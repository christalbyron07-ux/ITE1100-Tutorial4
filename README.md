# ITE 1100 - Tutorial 4: Git and GitHub Workflow

## Purpose
The purpose of this repository is to demonstrate and practice a simple workflow and collaboration between Git and GitHub, including creating a local repository, feature branching, resolving sync conflicts, and submitting pull requests for peer review.

## Author and Collaborator
* **Author:** Christal Byron (`christalbyron07-ux`)
* **Peer Reviewer:** Ronsdale Jones (`Ronsdalej`)

## Steps Followed
1. Created a GitHub account and installed Git software on my local machine.
2. Initialized a local repository using Git Bash and created a `feature-tutorial` branch.
3. Added my classmate, Ronsdale, as a collaborator on the GitHub repository.
4. Created a file named `info.py` containing a Python script that prints my first and last name, then committed it locally.
5. Fetched and merged the remote `main` branch into `feature-tutorial` using `--allow-unrelated-histories` to sync diverging commit histories.
6. Pushed the updated branch to GitHub, opened a Pull Request against `main`, and assigned Ronsdale as the peer reviewer.
7. Merged the `feature-tutorial` branch into the `main` branch once approved.
